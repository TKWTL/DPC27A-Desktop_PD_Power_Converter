# DPC27A 双语界面与字库

## 现行实现

- `i18n.c/.h` 以原英文字符串精确匹配 `i18n_table.inc`；保持 AddItem/AddPage/data.name、协议和格式占位符不变。无对应译文时返回原文，共 81 个清单键（恒等协议/型号条目不进入运行时字典）。
- 开机默认简体中文（`s_chinese=1`）；Settings → System → Language（中文界面）开=中文、关=英文，RAM-only。
- `U8G2_WITH_UNICODE` 已开启。两语共享 `UI_FONT=font_fusion_pixel_p12_zhcn`；菜单翻译使用 DPC_I18n_Text/DrawText/DrawLabel/TextWidth，中文经 UTF-8 解码，原 ASCII 绘制及数值仍可用 Disp_DrawStr。
- Dashboard 与图标页共用实时顶栏始终 ASCII，状态 UVP/NEG/EPR/PPS/SPR/DC。Statistics 译为系统数据；Reboot to ISP 译为“重启至ISP模式”。串口、协议、数字单位不翻译。小恐龙的 HI 分数前缀保持原文；端口菜单入口和页标题追加“设置”，系统数据 Req/VBUS 对应“请求电压 (V)”/“输入电压 (V)”。
- TEXT 选框高13 px、实际译文字宽+2，英文顶边=基线-10、中文=基线-11。左标题 clip 0..84，右数值区 86..118，ASCII 定点值按6 px右对齐，开关12×12位于 x=104。超宽标签使用现有水平滚动机制。
- About 按完整 UTF-8 码点在120 px区域折行，12 px行距最多六行。英文原文由 ui_conf.c 定义，译文须与该键完全匹配；当前中文描述为“1到3通道电源转换,支持PD/QC/SCP等快充”。本轮静态测宽中英文均6行；不是实机显示验证。

## 当前字库

| 来源 | 字形 |
|---|---|
| MiaoUI 原 h12w6（MIT） | 95 个 U+0020..U+007E，6×11 点阵、6 px 步进 |
| Fusion Pixel Font / Ark Pixel Font（SIL OFL 1.1） | 118 个汉字，12 px 步进 |
| 合计 | 213 字形、4333 B U8g2 RLE Unicode |

唯一数组 [font_fusion_pixel_p12_zhcn.c](MiaoUI/fonts/font_fusion_pixel_p12_zhcn.c) 是多源子集，并非完整 Fusion Pixel 或比例 ASCII 字库；保留文件名/符号名。同步清单 [i18n_zh_charset.txt](i18n_zh_charset.txt) 枚举全部已收录汉字；当前译文实际需要 112 个，其余为保留的历史字形。

汉字来源：

- IH01A `01933c4` 的 Fusion Pixel 12px RLE 子集50字、后续补充“据”“数”2字；原用户提供的 `lv_font_menucn_12(1).c` Fusion Pixel LVGL 子集24字。
- [Ark Pixel 12px common PNG](https://github.com/TakWolf/ark-pixel-font/tree/461d57118e1ccb1e987c1fa96313d4672e68e73a/assets/glyphs/12/cmap/common)（`461d57118e1ccb1e987c1fa96313d4672e68e73a`）：最初26字、About补充9字（换器到通道支持快充）、3字（等模式）、本轮4字（小压输入）。PNG 转11×11、x=0、y=-1、12 px advance，沿用 U8g2 RLE 参数。
- 原始完整 BDF 未用于此次构建，不代表整套字体点阵完全相同。保留 [LICENSE-OFL-FUSION](MiaoUI/fonts/LICENSE-OFL-FUSION)、[LICENSE-OFL-ARK](MiaoUI/fonts/LICENSE-OFL-ARK)、[MIT](MiaoUI/LICENSE) 与 [第三方声明](../../THIRD_PARTY_NOTICES.md)。

## 维护流程

1. 修改 i18n_table.inc，About 英文原文修改时同步 ui_conf.c；保留前缀、括号、格式说明符。
2. 扫描译文 Unicode 码点，只补缺字；优先复用原 Fusion Pixel 子集匹配参数的 RLE，没有则从同版本 Ark Pixel PNG 转码。禁止直接拼接完整字体数组或用未知许可字体代替。
3. 维护共享头、A/a 偏移、Unicode 起始索引、码点顺序、记录长度和终止符；更新字形总数及清单（当前计数字段为8 bit）。
4. 逐字解码验证新增像素和步进，保持已有记录，检查所有译文覆盖、About 六行及长标签；Clean Build 后检查 MAP 与实机两种显示方向。
5. 如取得完整 BDF，可用 bdfconv -m 选择码点，但必须保留原 h12w6 ASCII、中文基线、符号及许可证，不能以完整比例 ASCII 覆盖旧字形。

本轮新增4字逐像素与源 PNG 一致；原209条记录、ASCII 和索引块保持不变，213条记录静态解码通过。全部翻译所需汉字覆盖，两个电压标签静态测宽均为 78 px，适配84 px标题区。WCH 目标构建、最新 Flash 与板测未完成。旧版完整移植记录见 [此前文档](https://github.com/TKWTL/DPC27A-Desktop_PD_Power_Converter/blob/341b2c590010e1c9ccb11c7558f8f778ef4c64d2/Firmware/APP/I18N.md)。
