# DPC27A 中英文界面适配（2026-11-15）

## 实现

- 原英文为键：`APP/i18n.c/.h` 实现显示层精确查找。AddItem/AddPage/data.name 保持英文，翻译保留前导空格、横线及成对方括号；无匹配时返回原文。完整 [i18n_table.inc](i18n_table.inc) 共81个键，编译64个不同译文，17个协议/型号恒等项走原文回退，不重复占用字典。全部100个去重汉字在 [i18n_zh_charset.txt](i18n_zh_charset.txt)。
- Settings → System → Language 放在温度源选项之后、Reset Now 之前；OFF/ON=英文/简体中文，RAM-only、启动默认英文。启用后 UI 中显示“中文界面”。不改变索引、控制回调或采样。
- U8g2 的 `U8G2_WITH_UNICODE` 已在本地头文件开启；必须 Clean Build。Disp_DrawStr 仍为 ASCII 绘制，不全局改成 UTF-8。DPC_I18n_DrawText/DrawLabel/TextWidth 与所有 ASCII 页面共用 `font_fusion_pixel_p12_zhcn`，原独立 ASCII 字库已删除；语言仅决定翻译和解码方式。
- TEXT 页：实际 UTF-8 像素宽度 + 左右各1px留白，选框高13px，中英文顶边均=基线-11；不限制目标选框宽度，由 title clip 截断溢出区域。导航保存的宽度重新测量，切语言或文本页面切换重置横向滚动，不改菜单 ID/坐标系统。
- 128×80、图标30×30/Y=28、进度条Y=16、图标下划线和标题位置保持。Dashboard_Page 和 Dashboard_DrawStatusLine（包括图标页实时顶栏）保持 ASCII 内容及原列锚点，按实际字宽对齐，顶栏超宽时仅省略 Wmax 的 max。右数值区 86..118，INT/FIXED/SWITCH 数据逻辑、ASCII 数字右对齐和开关 x=104（右缘116、scrollbar 左缘118）保持；左 title clip 0..84。参数弹窗的标签翻译、ASCII 定点值单独右对齐，避免 UTF-8 截断。
- About 按完整 UTF-8 码点及像素宽度折行；中英文共用比例字体；压缩 About 的 URL 前缀及许可证短标签以保留六行和80px屏幕。烧屏提示和游戏结束文案参与翻译；中英文游戏结束行使用13px基线间距，分数标签按像素测宽，分数超宽时回退 ASCII。Dashboard 不翻译，串口/协议/数字单位不改。

## 字库来源与容量

原始完整 Fusion Pixel BDF 未能取得（历史附件无法恢复，公开 gzip 下载在当前环境失败）；不是重新编译完整 BDF。现有字库由真实已发布/已有字形合成：
- IH01A `01933c4` 的 `font_fusion_pixel_12_zh.c` 中95个ASCII及50个所需汉字直接复用 RLE；
- 用户此前的 Fusion Pixel 12px LVGL 子集 `lv_font_menucn_12(1).c` 提供24个补充汉字，按原1bpp像素和字形指标转为 U8g2 RLE。40个重叠汉字的两份点阵及指标相同；
- 上游 [Ark Pixel Font](https://github.com/TakWolf/ark-pixel-font/tree/461d57118e1ccb1e987c1fa96313d4672e68e73a/assets/glyphs/12/cmap/common) common 12px PNG 提供剩余26个汉字，保留11×11前景及12px advance，使用与现有汉字一致的基线。并非对原 Fusion Pixel BDF 的全部点阵逐字比对，视觉差异需要上板确认。
- `MiaoUI/fonts/font_fusion_pixel_p12_zhcn.c` 为 U8g2 RLE Unicode，完整195字形 **3655 B**；两种来源 OFL 1.1 授权原文随代码保存为 LICENSE-OFL-FUSION / LICENSE-OFL-ARK。字形数据未变，包含 95 个可打印 ASCII；原 1200 B 独立 ASCII 字库已移除。
- 新字库 + 64项32位双指针表名义512 B + 不同译文UTF-8/NUL共883 B（未合并）= 5050 B，只是数据估计，另有 Unicode 查找、菜单测宽、换行和工程链接开销。历史 text=54996/data=76 B、62KiB Flash 名义余量8416 B 是此前版本，不是本次的实测余量。

## 后续统一字形

如取得 Fusion Pixel 12px Proportional zh_Hans BDF（[上游](https://github.com/TakWolf/fusion-pixel-font)），建议用真实 BDF 统一重建字库，同步字符集；保留 OFL 许可证及比例字形布局。bdfconv 的 `-m` 选择码点，例：用 Python 生成映射字符串 `"32-126," + ",".join(str(ord(c)) for c in charset.strip())`，然后运行 `bdfconv -f 1 -b 0 -m "<映射字符串>" -n font_fusion_pixel_p12_zhcn -o font_fusion_pixel_p12_zhcn.c <源BDF>`，检查生成 C 头文件及所有码点覆盖再替换现有字库。不能直接照搬 IH01A 的89字子集，也不能使用 `-u` 当作字符清单路径。
